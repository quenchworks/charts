Quenchworks HAProxy is installed as {{ include "quench-common.fullname" . }}.

Reach it from inside the cluster:

  Load-balanced traffic (the http_in frontend, port {{ .Values.service.port }}):
    {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

  Stats + health (port {{ .Values.service.statsPort }}):
    {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.statsPort }}/stats
    {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.statsPort }}/healthz

  kubectl run lb-test --rm -it --image=curlimages/curl --restart=Never -- \
    curl -fsS http://{{ include "quench-common.fullname" . }}:{{ .Values.service.port }}/

Or port-forward the stats/health endpoint from your workstation:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} {{ .Values.service.statsPort }}:{{ .Values.service.statsPort }}
  curl http://127.0.0.1:{{ .Values.service.statsPort }}/stats
  curl http://127.0.0.1:{{ .Values.service.statsPort }}/healthz

Customize the load-balancing config by overriding config.haproxyConfig. The default
ships a stats/health listener on :{{ .Values.service.statsPort }} and a sample http frontend on :{{ .Values.service.port }}
that answers 200 itself; point its `backend app` at real servers, e.g.:

  config:
    haproxyConfig: |
      ...
      backend app
          server s1 10.0.0.1:80 check
          server s2 10.0.0.2:80 check

Keep the stats/health listener on :{{ .Values.service.statsPort }} (or update service.statsPort + the probes)
and bind only UNPRIVILEGED ports (>=1024): the container runs as uid 1001.

The image is nonroot (uid 1001), runs on a read-only root filesystem (emptyDir volumes
are mounted writable at /var/lib/haproxy for the pidfile + admin socket and at /tmp),
pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
