Quenchworks MLflow Tracking Server is installed as {{ include "quench-common.fullname" . }}.

The UI and REST API are served on port {{ .Values.service.port }} inside the cluster:

  http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Reach it from your machine with a port-forward:

  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  # then open the UI at http://localhost:{{ .Values.service.port }}/

Health / API:

  curl -fsS http://localhost:{{ .Values.service.port }}/health                                  # serving
  curl -fsS http://localhost:{{ .Values.service.port }}/api/2.0/mlflow/experiments/search        # list experiments

Point a client at the tracking server:

  export MLFLOW_TRACKING_URI=http://localhost:{{ .Values.service.port }}

NOTE: MLflow ships no built-in authentication. networkPolicy.allowExternal is
{{ .Values.networkPolicy.allowExternal }}; front it with an authenticating ingress/proxy before exposing it.

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
