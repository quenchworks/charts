QuenchWorks backup-stack is installed in {{ .Release.Namespace }}.

  Velero      backup location "default" -> s3://velero on backup-seaweedfs
  SeaweedFS   http://backup-seaweedfs:8333 (keys in Secret backup-s3)

Back up a namespace:

  kubectl apply -n {{ .Release.Namespace }} -f - <<YAML
  apiVersion: velero.io/v1
  kind: Backup
  metadata: { name: my-app-1 }
  spec: { includedNamespaces: [my-app] }
  YAML

The store lives in this cluster. For disaster recovery, point
velero.backupStorageLocation at storage outside it, or replicate the bucket.
