  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 8443:{{ .Values.service.httpsPort }}
  curl --cacert ca.crt https://localhost:8443/

FINISH THE INSTALLER. Matomo has NO environment-variable configuration -- everything lives
in config.ini.php, which its WEB INSTALLER writes on first run. So the chart cannot
pre-seed anything; open the URL above and complete the wizard once.

You will need a MySQL or MariaDB database. This chart bundles none -- pair it with
quench/mariadb or use a managed instance.

{{ if not .Values.persistence.enabled }}
!! persistence.enabled is FALSE. config/ is an emptyDir, so config.ini.php is LOST on every
   pod restart and Matomo will ask you to reinstall -- against a database that already has
   its schema, which is a confusing half-broken state. Fine for a smoke test, never for

{{- else }}
config.ini.php persists on a {{ .Values.persistence.size }} PVC, so the install survives
restarts and rollouts.
{{- end }}

replicaCount is capped at 1 by the schema. That is deliberate: config/ is ReadWriteOnce so
a second replica cannot mount it, and two Matomos running their own archiving would
double-process the same data. Give the pod more CPU instead, or move config/ to a
ReadWriteMany volume first.

The image is pinned by digest and cosign-signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
