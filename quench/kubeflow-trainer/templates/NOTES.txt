Kubeflow Trainer {{ .Chart.AppVersion }} and JobSet are running in {{ .Release.Namespace }}.

Define a runtime (or install upstream's ClusterTrainingRuntimes for PyTorch, DeepSpeed, JAX, MLX and
XGBoost from kubeflow/trainer manifests/base/runtimes), then submit a TrainJob:

  kubectl apply -f - <<'YAML'
  apiVersion: trainer.kubeflow.org/v1alpha1
  kind: TrainJob
  metadata: { name: demo }
  spec:
    runtimeRef: { name: torch-distributed }
    trainer:
      numNodes: 2
      image: your/training-image
  YAML

Watch it: kubectl get trainjob,jobset
