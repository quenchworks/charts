Ergo serves {{ .Values.networkName }} as {{ .Values.serverName }}: IRC on {{ .Values.service.port }}{{ if include "quench-common.tls.enabled" . }} and IRC over TLS on {{ .Values.service.tlsPort }}{{ end }}.

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 6667:{{ .Values.service.port }}

Become an IRC operator with /OPER admin <password>; the password:

  kubectl get secret -n {{ .Release.Namespace }} {{ include "ergo.secretName" . }} -o jsonpath='{.data.oper-password}' | base64 -d

Users register their nick with /msg NickServ REGISTER <password>.
