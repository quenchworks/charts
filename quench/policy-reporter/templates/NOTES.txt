Policy Reporter {{ .Chart.AppVersion }} is installed as {{ include "quench-common.fullname" . }}. It reads the
PolicyReport and ClusterPolicyReport results Kyverno (or another engine) writes.

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} 8080:{{ .Values.service.port }}
{{- if .Values.rest.enabled }}
  curl http://127.0.0.1:8080/v1/namespaced-resources/results    # REST API
{{- end }}
{{- if .Values.metrics.enabled }}
  curl http://127.0.0.1:8080/metrics                        # policy_report_result
{{- end }}

Notification targets (Slack, Loki, Elasticsearch, webhooks, ...) go under `config.target`
in values, in Policy Reporter's own config format.
