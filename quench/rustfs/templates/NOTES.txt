S3-compatible object storage, single node. The S3 API is served on port
{{ .Values.service.port }} from inside the cluster:

  http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

{{- if .Values.console.enabled }}

The web console is enabled on port {{ .Values.console.port }}.
{{- end }}

{{- if .Values.auth.enabled }}

S3 auth is enabled. Get the root credentials from the Secret:

  ACCESS_KEY=$(kubectl get secret --namespace {{ .Release.Namespace }} {{ include "rustfs.secretName" . }} \
    -o jsonpath="{.data.{{ include "rustfs.secretAccessKeyKey" . }}}" | base64 -d)
  SECRET_KEY=$(kubectl get secret --namespace {{ .Release.Namespace }} {{ include "rustfs.secretName" . }} \
    -o jsonpath="{.data.{{ include "rustfs.secretSecretKeyKey" . }}}" | base64 -d)

Use them with any S3 client, e.g. the AWS CLI from a pod in the cluster:

  kubectl run awscli --rm -i --restart=Never --image=amazon/aws-cli \
    --env AWS_ACCESS_KEY_ID="$ACCESS_KEY" \
    --env AWS_SECRET_ACCESS_KEY="$SECRET_KEY" -- \
    --endpoint-url http://{{ include "quench-common.fullname" . }}:{{ .Values.service.port }} \
    s3 mb s3://my-bucket
{{- else }}

S3 auth is DISABLED: RustFS falls back to its built-in default identity
(rustfsadmin/rustfsadmin). The NetworkPolicy is the only boundary. Set
auth.enabled=true (default) for deterministic credentialed access.

  kubectl run awscli --rm -i --restart=Never --image=amazon/aws-cli \
    --env AWS_ACCESS_KEY_ID=rustfsadmin --env AWS_SECRET_ACCESS_KEY=rustfsadmin -- \
    --endpoint-url http://{{ include "quench-common.fullname" . }}:{{ .Values.service.port }} \
    s3 mb s3://my-bucket
{{- end }}

NOTE: as a young project, RustFS emits some benign ERROR lines at boot (an
expired-TLS remote check and transient AccessDenied during init). These are not
failures — the /health probe on port {{ .Values.service.port }} is the source of truth for readiness.

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
