Quenchworks Drupal is installed as {{ include "quench-common.fullname" . }}.

The public site, /admin and the installer are served on port {{ .Values.service.port }} inside the cluster:

  http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Reach it from your machine with a port-forward:

  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  # then open the site at   http://localhost:{{ .Values.service.port }}/
  # and finish the install at http://localhost:{{ .Values.service.port }}/core/install.php

Database:

    host     : {{ include "drupal.db.host" . }}
    port     : {{ include "drupal.db.port" . }}
    database : {{ include "drupal.db.name" . }}

{{- else }}
  External database (mysql.enabled=false).
    host     : {{ include "drupal.db.host" . }}
    port     : {{ include "drupal.db.port" . }}
    database : {{ include "drupal.db.name" . }}
    user     : {{ include "drupal.db.user" . }}
  Ensure this MySQL/MariaDB is reachable and the database/user exist.
{{- end }}
  The DB password and Drupal hash salt are injected from a Secret as DRUPAL_* env vars and
  read by the chart-supplied settings.php — they never appear in the pod's argv.

Public files:
{{- if .Values.persistence.enabled }}
  PVC mounted at {{ .Values.persistence.mountPath }} ({{ .Values.persistence.size }}).
{{- else }}
  emptyDir (NOT persistent). Uploaded files are lost on pod restart — enable persistence for
  any real use.
{{- end }}
  The rootfs is read-only: Drupal core, modules and themes are baked into the signed image,
  and in-place UI updates are disabled. Rebuild the image to change code.

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
