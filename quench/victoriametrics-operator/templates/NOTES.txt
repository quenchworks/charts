The VictoriaMetrics Operator is running as {{ include "quench-common.fullname" . }} and watches
{{ if .Values.watchNamespaces }}{{ join ", " .Values.watchNamespaces }}{{ else }}every namespace{{ end }} for VMSingle, VMCluster, VMAgent, VMAlert, VMAuth,
VMServiceScrape and the other operator.victoriametrics.com resources (CRDs installed with the chart).

A single-node VictoriaMetrics and an agent that scrapes every VMServiceScrape into it:

  apiVersion: operator.victoriametrics.com/v1beta1
  kind: VMSingle
  metadata: { name: main }
  spec: { retentionPeriod: "1" }
  ---
  apiVersion: operator.victoriametrics.com/v1beta1
  kind: VMAgent
  metadata: { name: main }
  spec:
    selectAllByDefault: true
    remoteWrite: [{ url: "http://vmsingle-main:8429/api/v1/write" }]

unless you set spec.image on them.

crds/crds.yaml yourself before upgrading the chart across operator releases.
