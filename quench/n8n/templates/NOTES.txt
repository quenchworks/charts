Quenchworks n8n is installed as {{ include "quench-common.fullname" . }}.
{{- if include "quench-common.tls.enabled" . }}

TLS is on: n8n serves HTTPS itself (native TLS) on Service port {{ .Values.service.httpsPort }},
which replaces the plain-HTTP port in the URLs below:

  https://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local{{ if ne (int .Values.service.httpsPort) 443 }}:{{ .Values.service.httpsPort }}{{ end }}/healthz

The certificate is in Secret {{ include "quench-common.tls.secretName" . }}; trust its ca.crt (self-signed by default):

  kubectl get secret --namespace {{ .Release.Namespace }} {{ include "quench-common.tls.secretName" . }} -o jsonpath='{.data.ca\.crt}' | base64 -d > ca.crt
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 8443:{{ .Values.service.httpsPort }}
  curl --cacert ca.crt https://localhost:8443/healthz
{{- end }}

The editor UI + REST API + webhooks are served on port {{ .Values.service.port }}:

  http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Reach the UI from your machine over a port-forward:

  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 5678:{{ .Values.service.port }}
  # then open http://127.0.0.1:5678/  (n8n prompts you to create the owner account on first visit)

Health check:

  curl -fsS http://127.0.0.1:5678/healthz
  # -> {"status":"ok"}

Encryption key:
  N8N_ENCRYPTION_KEY protects stored credentials and MUST stay stable for the life of
  the instance. It is held in a Secret (generated once if you did not supply one):

    kubectl get secret --namespace {{ .Release.Namespace }} {{ include "n8n.encryptionSecretName" . }} \
      -o jsonpath="{.data.{{ include "n8n.encryptionSecretKey" . }}}" | base64 -d

  Back this value up. Losing it makes every stored credential undecryptable.

Production hardening:
  Set the public host so n8n builds correct editor/webhook/OAuth-callback URLs:

    n8n:
      host: n8n.example.com
      protocol: https
