The Knative Operator {{ .Chart.AppVersion }} is running in {{ .Release.Namespace }}.

Install Knative Serving (with the Kourier ingress):

  kubectl create namespace knative-serving
  kubectl apply -f - <<'YAML'
  apiVersion: operator.knative.dev/v1beta1
  kind: KnativeServing
  metadata: { name: knative-serving, namespace: knative-serving }
  spec:
    ingress: { kourier: { enabled: true } }
    config: { network: { ingress-class: kourier.ingress.networking.knative.dev } }
  YAML

Install Knative Eventing:

  kubectl create namespace knative-eventing
  kubectl apply -f - <<'YAML'
  apiVersion: operator.knative.dev/v1beta1
  kind: KnativeEventing
  metadata: { name: knative-eventing, namespace: knative-eventing }
  YAML

Watch them: kubectl get knativeserving,knativeeventing -A
