Quenchworks MariaDB Operator {{ .Chart.AppVersion }} is installed as {{ include "quench-common.fullname" . }}.

Create a MariaDB (it uses the QuenchWorks mariadb image by default):

  apiVersion: k8s.mariadb.com/v1alpha1
  kind: MariaDB
  metadata:
    name: mariadb
  spec:
    rootPasswordSecretKeyRef:
      name: mariadb-root
      key: password
      generate: true
    storage:
      size: 1Gi

The admission webhook is not included in this release, so the API server does
not validate MariaDB resources before the operator reads them.
