Quenchworks Garage is installed as {{ include "quench-common.fullname" . }}.

Garage is an S3-compatible object store (AGPL-3.0), single node — the alternative
to the default Quenchworks object store, SeaweedFS.

The S3 API is served on port {{ .Values.service.port }} from inside the cluster:

  http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

NOTE: Garage uses an S3 region of "garage" — pass `--region garage` to your S3 client.

{{- if .Values.auth.enabled }}

Get the S3 admin credentials from the Secret:

  ACCESS_KEY=$(kubectl get secret --namespace {{ .Release.Namespace }} {{ include "garage.secretName" . }} \
    -o jsonpath="{.data.{{ include "garage.secretAccessKeyKey" . }}}" | base64 -d)
  SECRET_KEY=$(kubectl get secret --namespace {{ .Release.Namespace }} {{ include "garage.secretName" . }} \
    -o jsonpath="{.data.{{ include "garage.secretSecretKeyKey" . }}}" | base64 -d)

Use them with any S3 client, e.g. the AWS CLI from a pod in the cluster
(note the `--region garage`):

  kubectl run awscli --rm -i --restart=Never --image=amazon/aws-cli \
    --env AWS_ACCESS_KEY_ID="$ACCESS_KEY" \
    --env AWS_SECRET_ACCESS_KEY="$SECRET_KEY" -- \
    --endpoint-url http://{{ include "quench-common.fullname" . }}:{{ .Values.service.port }} \
    --region garage s3 mb s3://my-bucket
{{- if .Values.config.defaultBucket }}

A default bucket "{{ .Values.config.defaultBucket }}" was created and granted to the admin key on first boot.
{{- end }}
{{- else }}

S3 auth is DISABLED in values, but Garage always requires a signed S3 request.
A key is created on first boot and surfaced in the pod logs:

  kubectl logs {{ include "quench-common.fullname" . }}-0
{{- end }}

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
