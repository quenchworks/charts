The Beszel hub is on {{ include "quench-common.fullname" . }}:{{ .Values.service.port }}.

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 8090:{{ .Values.service.port }}

Log in as {{ .Values.admin.email }} with the password from:

  kubectl get secret -n {{ .Release.Namespace }} {{ include "beszel.secretName" . }} -o jsonpath='{.data.password}' | base64 -d

The admin is created on the first start only. To monitor the nodes, open "Add system", copy the
public key and token into a Secret (keys key and token) and install with agent.enabled=true and
agent.existingSecret=<that Secret>.
