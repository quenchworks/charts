Quenchworks Percona XtraDB Cluster Operator {{ .Chart.AppVersion }} is installed as {{ include "quench-common.fullname" . }}.
It manages PerconaXtraDBCluster resources in the {{ .Release.Namespace }} namespace.

Create a cluster with spec.crVersion set to {{ .Chart.AppVersion }}. The operator
uses its own image as the pods' init image, and for any other crVersion it
rewrites that image reference by tag, which a digest-pinned image does not have.
Set spec.initContainer.image to run another version.
