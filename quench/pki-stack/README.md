# Quenchworks pki-stack

Your own certificate authority for a Kubernetes cluster, in one install:

- [step-ca](https://smallstep.com/docs/step-ca/) is the CA.
- [cert-manager](https://cert-manager.io) runs the certificate lifecycle.
- [step-issuer](https://github.com/smallstep/step-issuer) lets cert-manager sign through step-ca.
- [trust-manager](https://cert-manager.io/docs/trust/trust-manager/) puts the CA root into every namespace.

A post-install Job wires them: once step-ca answers, it reads the CA root and the JWK
provisioner's key id, then creates the `StepClusterIssuer` `<release>-step-ca` and a trust
`Bundle` that writes the root into ConfigMap `<release>-root-ca` in every namespace.
Every image is minimal, nonroot, 0-CVE, cosign-signed and pinned by digest.

```
Certificate (issuerRef <release>-step-ca) -> cert-manager -> step-issuer -> step-ca signs
step-ca root -> trust-manager Bundle -> ConfigMap <release>-root-ca in every namespace
```

## Install

One per cluster (cert-manager, the CRDs and the cluster issuer are cluster-wide):

```bash
helm install pki oci://ghcr.io/quenchworks/charts/pki-stack -n pki --create-namespace
kubectl wait --for=condition=Ready stepclusterissuer/pki-step-ca --timeout=5m
```

Then a certificate:

```yaml
apiVersion: cert-manager.io/v1
kind: Certificate
metadata: {name: web, namespace: my-app}
spec:
  secretName: web-tls
  dnsNames: [web.my-app.svc]
  issuerRef: {group: certmanager.step.sm, kind: StepClusterIssuer, name: pki-step-ca}
```

Clients in any namespace trust it by mounting ConfigMap `pki-root-ca` (key `ca.crt`).

## The CA passwords

The stack generates the CA key password and the provisioner password into Secret
`pki-stack-ca-auth` before step-ca bootstraps. The CA keys on the step-ca PVC are encrypted
with them: back up the Secret and the PVC together, and never delete the Secret while the
PVC exists. To bring your own, create a Secret with keys `password` and
`provisioner-password` and set `step-ca.auth.existingSecret` to its name.

## Values

| Key | Default | Notes |
|---|---|---|
| `step-ca.*`, `cert-manager.*`, `step-issuer.*`, `trust-manager.*` | | Passed to each subchart. |
| `step-ca.auth.existingSecret` | `pki-stack-ca-auth` | Generated by the stack when left at this name. |
| `wiring.enabled` | `true` | The Job that creates the issuer and the Bundle. |
| `wiring.bundleKey` | `ca.crt` | Key of the root in each namespace's ConfigMap. |
| `wiring.namespaceSelector` | `{}` | Limit which namespaces get the root. |
