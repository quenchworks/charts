Quenchworks KServe {{ .Chart.AppVersion }} is installed as {{ include "quench-common.fullname" . }} (mode: {{ .Values.deploymentMode }}).

Serve a model with any container that speaks HTTP:

  apiVersion: serving.kserve.io/v1beta1
  kind: InferenceService
  metadata:
    name: my-model
  spec:
    predictor:
      containers:
        - name: kserve-container
          image: <your model server image>

The controller creates a Deployment and a Service named my-model-predictor.
No ingress is created; expose the Service yourself.

The built-in model-server runtimes (sklearn, xgboost, huggingface, ...) are not
included in this chart and have no QuenchWorks images yet.
