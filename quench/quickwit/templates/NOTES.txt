Quenchworks quickwit is installed as {{ include "quench-common.fullname" . }}.
{{- if include "quench-common.tls.enabled" . }}

TLS is on: Quickwit serves HTTPS itself (native TLS) on Service port {{ .Values.service.httpsPort }},
which replaces the plain-HTTP port in the URLs below:

  https://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local{{ if ne (int .Values.service.httpsPort) 443 }}:{{ .Values.service.httpsPort }}{{ end }}/health/readyz

The certificate is in Secret {{ include "quench-common.tls.secretName" . }}; trust its ca.crt (self-signed by default):

  kubectl get secret --namespace {{ .Release.Namespace }} {{ include "quench-common.tls.secretName" . }} -o jsonpath='{.data.ca\.crt}' | base64 -d > ca.crt
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 8443:{{ .Values.service.httpsPort }}
  curl --cacert ca.crt https://localhost:8443/health/readyz
{{- end }}

Reach the REST API + bundled admin UI from inside the cluster:

  http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Port-forward it to your laptop:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} 7280:{{ .Values.service.port }}
  # then open http://127.0.0.1:7280/ui   (bundled admin dashboard)

Health checks:

  curl http://127.0.0.1:7280/health/livez   # -> 200 once the server is up
  curl http://127.0.0.1:7280/health/readyz  # -> 200 once ready to serve

List indexes / create one via the REST API:

  curl http://127.0.0.1:7280/api/v1/indexes
  curl -XPOST http://127.0.0.1:7280/api/v1/indexes \
    -H 'content-type: application/yaml' \
    --data-binary @my-index-config.yaml

Index data + local split cache persist on the PVC at /quickwit/qwdata. This chart
runs a single-node (standalone) Quickwit with local file storage; for a distributed
cluster front it with object storage (S3/GCS/Azure) and a shared metastore via
extraEnvVars (QW_*).

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
