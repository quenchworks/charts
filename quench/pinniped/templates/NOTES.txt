Quenchworks Pinniped Concierge {{ .Chart.AppVersion }} is installed as {{ include "pinniped.name" . }}.

Point it at an identity provider, e.g. an OIDC issuer:

  apiVersion: authentication.concierge.pinniped.dev/v1alpha1
  kind: JWTAuthenticator
  metadata: { name: my-oidc }
  spec:
    issuer: https://issuer.example.com
    audience: <a value unique to this cluster>

Then hand users a kubeconfig that logs them in through it (run with admin access):

  pinniped get kubeconfig --concierge-authenticator-type jwt --concierge-authenticator-name my-oidc > user-kubeconfig.yaml
