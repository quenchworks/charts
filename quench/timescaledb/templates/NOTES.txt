Quenchworks TimescaleDB is installed as {{ include "quench-common.fullname" . }}.

Connect from inside the cluster:

  Host: {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local
  Port: {{ .Values.service.port }}
  User: {{ .Values.auth.username }}
  Database: {{ .Values.auth.database | default .Values.auth.username }}

{{- if .Values.auth.enabled }}

Get the password:

  kubectl get secret --namespace {{ .Release.Namespace }} {{ include "timescaledb.secretName" . }} \
    -o jsonpath="{.data.{{ include "timescaledb.secretPasswordKey" . }}}" | base64 -d

Then, from a client pod:

  PGPASSWORD="<password>" psql -h {{ include "quench-common.fullname" . }} -U {{ .Values.auth.username }}

The TimescaleDB extension is loaded on first init. Confirm it is available:

  psql ... -tAc "SELECT extversion FROM pg_extension WHERE extname='timescaledb'"
{{- else }}

WARNING: auth is disabled.
{{- end }}

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
