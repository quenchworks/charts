The Flink Kubernetes Operator {{ .Chart.AppVersion }} is running in {{ .Release.Namespace }}.

Run a Flink cluster with a FlinkDeployment in {{ .Release.Namespace }} (the "flink" service account
for jobs is created there):

  kubectl apply -n {{ .Release.Namespace }} -f - <<'YAML'
  apiVersion: flink.apache.org/v1beta1
  kind: FlinkDeployment
  metadata: { name: session }
  spec:
    image: ghcr.io/quenchworks/images/flink:2.3.0
    flinkVersion: v2_3
    serviceAccount: flink
    flinkConfiguration:
      kubernetes.entry.path: /usr/bin/docker-entrypoint.sh
    jobManager: { resource: { memory: "1024m", cpu: 0.5 } }
    taskManager: { resource: { memory: "1024m", cpu: 0.5 } }
  YAML

Watch it: kubectl -n {{ .Release.Namespace }} get flinkdeployment
