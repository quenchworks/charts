Deploy applications by baking WARs into a derived image at /var/lib/jetty/webapps, or
by mounting them there with extraVolumes / extraVolumeMounts. Jetty deploys a WAR, an
unpacked directory or a context XML file per entry.

The image is nonroot (uid 1001) on a read-only root filesystem (an emptyDir at /tmp
holds unpacked WARs and work files), pinned by digest and signed:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
