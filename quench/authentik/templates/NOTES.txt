It runs as TWO nonroot (uid 1001) workloads from the same image:
  - server ({{ include "authentik.componentFullname" (dict "ctx" . "component" "server") }}) — web UI + API on container ports 9000 (HTTP) and 9443 (HTTPS)
  - worker ({{ include "authentik.componentFullname" (dict "ctx" . "component" "worker") }}) — background tasks + DB migrations (no listener)

The Service exposes the SERVER on ports {{ .Values.service.port }} (HTTP) and {{ .Values.service.httpsPort }} (HTTPS):

  {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  # health:
  curl http://127.0.0.1:{{ .Values.service.port }}/-/health/ready/
