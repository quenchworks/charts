listmonk is on {{ include "quench-common.fullname" . }}:{{ .Values.service.port }}.

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 9000:{{ .Values.service.port }}

Open http://localhost:9000/admin and log in as "{{ .Values.admin.username }}" with the password from:

  kubectl get secret -n {{ .Release.Namespace }} {{ include "listmonk.adminSecretName" . }} -o jsonpath='{.data.{{ .Values.admin.existingSecretKey }}}' | base64 -d

The admin is created by the install step on an empty database only. Set the root URL, SMTP and
the media provider under Settings.
