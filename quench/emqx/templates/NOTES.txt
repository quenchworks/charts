Quenchworks EMQX (distributed MQTT broker) is installed as {{ include "quench-common.fullname" . }}.

EMQX runs nonroot on a read-only root filesystem as a single-node StatefulSet. The
Service exposes:

  mqtt       {{ .Values.service.ports.mqtt }}    MQTT 5.0 (TCP)
  mqttssl    {{ .Values.service.ports.mqttssl }}    MQTT over TLS
  ws         {{ .Values.service.ports.ws }}    MQTT over websockets
  wss        {{ .Values.service.ports.wss }}    MQTT over secure websockets
  dashboard  {{ .Values.service.ports.dashboard }}   web dashboard + REST API + /status

  {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local

Open the dashboard over a port-forward (default user `admin`):

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} {{ .Values.service.ports.dashboard }}:{{ .Values.service.ports.dashboard }}
  # then browse http://127.0.0.1:{{ .Values.service.ports.dashboard }}  (admin / <dashboardPassword>)
  curl http://127.0.0.1:{{ .Values.service.ports.dashboard }}/status
