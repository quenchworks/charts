The server runs nonroot with a read-only rootfs and serves an OpenAI-compatible
API {{ if $tlsOn }}over HTTPS (native TLS) on container port 8443{{ else }}on container port 8000{{ end }} for model "{{ .Values.model }}"; the Service exposes it
on port {{ if $tlsOn }}{{ .Values.service.httpsPort }}{{ else }}{{ .Values.service.port }}{{ end }}:

  {{ if $tlsOn }}https://{{ end }}{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ if $tlsOn }}{{ .Values.service.httpsPort }}{{ else }}{{ .Values.service.port }}{{ end }}

Model load is slow on CPU (weights are downloaded into the persistent cache on
first boot, then loaded into RAM). The startupProbe waits patiently; watch it:

  kubectl rollout status -n {{ .Release.Namespace }} statefulset/{{ include "quench-common.fullname" . }}

Then query the API over a port-forward:

{{ if $tlsOn }}  kubectl get secret -n {{ .Release.Namespace }} {{ include "quench-common.tls.secretName" . }} -o jsonpath='{.data.ca\.crt}' | base64 -d > ca.crt
{{ end }}  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} {{ $pf }}
  curl {{ $cacert }}{{ $local }}/health
  curl {{ $cacert }}{{ $local }}/v1/models
  curl {{ $cacert }}{{ $local }}/v1/completions \
    -H 'Content-Type: application/json' \
    -d '{"model":"{{ .Values.model }}","prompt":"hello","max_tokens":16}'
{{- end }}

{{ if .Values.persistence.enabled -}}
Downloaded model weights persist on a {{ .Values.persistence.size }} PersistentVolume mounted at
/opt/vllm/.cache (HF_HOME). Gated models need an HF token via extraEnvVars (HF_TOKEN).
{{- else -}}
persistence.enabled=false: the HF cache is an emptyDir, so model weights are
RE-DOWNLOADED on every pod restart. Enable persistence for anything beyond a test.
{{- end }}

This is the CPU-only image (prefer an avx512f/avx2 host CPU). GPU acceleration is
out of scope for this chart.

The image is pinned by digest and signed. Verify it:

  cosign verify ghcr.io/quenchworks/images/vllm \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
