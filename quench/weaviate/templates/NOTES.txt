Quenchworks Weaviate is installed as {{ include "quench-common.fullname" . }}.

The server runs nonroot and serves the REST API on container port {{ .Values.service.httpPort }}
and gRPC on port {{ .Values.service.grpcPort }}; the Service exposes both:

  REST: {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.httpPort }}
  gRPC: {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.grpcPort }}

Check readiness and query the schema over a port-forward:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} {{ .Values.service.httpPort }}:{{ .Values.service.httpPort }}
  curl http://127.0.0.1:{{ .Values.service.httpPort }}/v1/.well-known/ready
  curl http://127.0.0.1:{{ .Values.service.httpPort }}/v1/schema
