ScyllaDB Operator is running in {{ .Release.Namespace }} with its admission webhook ({{ include "quench-common.fullname" . }}-webhook).

Create a ScyllaCluster to get a cluster (examples: https://operator.docs.scylladb.com). The operator runs its sidecar
inside each ScyllaDB pod and expects the upstream ScyllaDB image layout there (/docker-entrypoint.py, /usr/bin/bash),
which the QuenchWorks scylladb image does not have yet; set spec.repository to an image that provides it.

The ClusterRoles are cluster-scoped (scylladb:*): install the operator once per cluster.
