Quenchworks navidrome is installed as {{ include "quench-common.fullname" . }}.

{{- if include "quench-common.tls.enabled" . }}

Reach the web UI / Subsonic API over HTTPS (native TLS) from inside the cluster:

  https://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local{{ if ne (int .Values.service.httpsPort) 443 }}:{{ .Values.service.httpsPort }}{{ end }}

The certificate is in Secret {{ include "quench-common.tls.secretName" . }}; trust its ca.crt
(self-signed by default). Port-forward it to your laptop:

  kubectl get secret {{ include "quench-common.tls.secretName" . }} -o jsonpath='{.data.ca\.crt}' | base64 -d > ca.crt
  kubectl port-forward svc/{{ include "quench-common.fullname" . }} 8443:{{ .Values.service.httpsPort }}
  # then open https://localhost:8443

Health check:

  curl --cacert ca.crt https://localhost:8443/ping   # -> HTTP 200
{{- else }}

Reach the web UI / Subsonic API from inside the cluster:

  http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Port-forward it to your laptop:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} 4533:{{ .Values.service.port }}
  # then open http://127.0.0.1:4533

Health check:

  curl http://127.0.0.1:4533/ping   # -> HTTP 200
{{- end }}

On first visit navidrome walks you through creating the initial admin account.

State (SQLite DB + scan cache + artwork) persists on the PVC at /data. The music
library is mounted read-only at /music; a default install uses an empty ephemeral
dir, so point `music.persistence.existingClaim` (or extraVolumes) at your library.

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
