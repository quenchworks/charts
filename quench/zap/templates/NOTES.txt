The ZAP API daemon answers on http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}:{{ .Values.service.port }}/
(the Service names are ZAP aliases; any other Host header is proxied, not answered as the API).

API key:

  kubectl get secret -n {{ .Release.Namespace }} {{ include "zap.secretName" . }} -o jsonpath='{.data.api-key}' | base64 -d

For example, from a pod in the cluster:

  curl "http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}:{{ .Values.service.port }}/JSON/core/view/version/?apikey=<key>"

Only scan systems you are authorized to test.
