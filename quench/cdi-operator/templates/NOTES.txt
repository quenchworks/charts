The CDI operator is running in {{ .Release.Namespace }}{{ if .Values.cdi.create }} and deploys CDI from the resource "cdi"{{ end }}.

  Ready:   kubectl wait cdi cdi --for=condition=Available --timeout=10m
  Import:  create a DataVolume (cdi.kubevirt.io/v1beta1) with spec.source.http.url and spec.storage;
           CDI fills a PVC of the same name with the converted disk image.

Before `helm uninstall`, run `kubectl delete cdi cdi` and wait for it to go: the operator removes CDI.
