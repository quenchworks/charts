Quenchworks memcached is installed as {{ include "quench-common.fullname" . }}.

Connect from inside the cluster:

  Endpoint: {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

memcached has no in-image client. Try it from a throwaway pod over the ASCII protocol:

  kubectl run mc-test --rm -it --image=busybox --restart=Never -- \
    sh -c 'echo -e "set qw 0 0 5\r\nhello\r\nget qw\r" | nc {{ include "quench-common.fullname" . }} {{ .Values.service.port }}'

Cache size is {{ .Values.memcached.memoryLimitMB }}MB ({{ if .Values.autoscaling.enabled }}autoscaling {{ .Values.autoscaling.minReplicas }}–{{ .Values.autoscaling.maxReplicas }} pods on CPU{{ else }}{{ .Values.replicaCount }} replica(s){{ end }}).

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
