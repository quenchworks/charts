Quenchworks Plone {{ .Chart.AppVersion }} (backend) is installed as {{ include "quench-common.fullname" . }}.

Reach it from inside the cluster:

  http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Port-forward it to your laptop:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} 8080:{{ .Values.service.port }}
  curl -H 'Accept: application/json' http://127.0.0.1:8080/{{ .Values.site.id | default "Plone" }}/++api++

The admin user is {{ .Values.admin.user }}. Its password:

  kubectl get secret {{ .Values.admin.existingSecret | default (include "quench-common.fullname" .) }} -n {{ .Release.Namespace }} \
    -o jsonpath='{.data.{{ .Values.admin.existingSecretKey | default "admin-password" }}}' | base64 -d

{{- if .Values.relstorage.existingSecret }}

Storage: RelStorage on PostgreSQL (DSN from Secret {{ .Values.relstorage.existingSecret }}).
{{- else }}

Storage: ZODB FileStorage and blobs on the PVC at /data. Keep replicaCount at 1.
{{- end }}

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
