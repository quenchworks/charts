Kubescape runs in {{ .Release.Namespace }}: operator, kubescape (configuration scanner),
kubevuln (image vulnerability scanner) and storage (results API server).

The operator scans the cluster at startup and scans each new container image as pods
appear. Results are Kubernetes objects served by storage:

  kubectl get workloadconfigurationscansummaries -A
  kubectl get vulnerabilitymanifestsummaries -A

One release per cluster: the components address each other by fixed Service names.
