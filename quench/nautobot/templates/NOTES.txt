Nautobot answers on http://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}:{{ .Values.service.port }}/

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}

Sign in as {{ .Values.admin.user }}. Its password:

  kubectl get secret -n {{ .Release.Namespace }} {{ include "nautobot.secretName" . }} -o jsonpath='{.data.admin-password}' | base64 -d

API tokens: create one in the UI (user menu, API Tokens) or POST /api/users/tokens/ with HTTP Basic auth.
Reaching it under another host name (an Ingress): add the host to allowedHosts and its origin to csrfTrustedOrigins.

Plain HTTP (the bundled uWSGI has no TLS): put an Ingress with TLS in front before exposing it.
