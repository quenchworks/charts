The TiDB Operator {{ .Chart.AppVersion }} is running in {{ .Release.Namespace }}.

Create a cluster (PD, TiKV and TiDB, one of each):

  kubectl create namespace tidb
  kubectl apply -n tidb -f - <<'YAML'
  apiVersion: pingcap.com/v1alpha1
  kind: TidbCluster
  metadata: { name: basic }
  spec:
    version: v8.5.8
    pd:   { baseImage: pingcap/pd,   replicas: 1, requests: { storage: 1Gi } }
    tikv: { baseImage: pingcap/tikv, replicas: 1, requests: { storage: 1Gi } }
    tidb: { baseImage: pingcap/tidb, replicas: 1, service: { type: ClusterIP } }
  YAML

Connect with any MySQL client to basic-tidb.tidb:4000 (user root, no password).
