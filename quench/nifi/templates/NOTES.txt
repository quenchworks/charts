Quenchworks NiFi is installed as {{ include "quench-common.fullname" . }} (single node).

The first start takes a few minutes. Then open the UI:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} 8443:8443
  https://localhost:8443/nifi/

The certificate is self-signed (generated by NiFi). Log in with:

  kubectl get secret {{ include "nifi.secretName" . }} -o jsonpath='{.data.username}' | base64 -d
  kubectl get secret {{ include "nifi.secretName" . }} -o jsonpath='{.data.password}' | base64 -d

NiFi rejects requests whose Host header it does not know. Add the name you expose it
under to proxyHosts.

The image is pinned by digest and signed. Verify it:

  cosign verify ghcr.io/quenchworks/images/nifi \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
