Quenchworks DocumentDB is installed as {{ include "quench-common.fullname" . }}.
This is a self-contained MongoDB-compatible server (PostgreSQL 17 + documentdb
extension + pg_documentdb_gw gateway). Connect a mongo client straight to it.

Connect from inside the cluster:

  Host: {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local
  Port: {{ .Values.service.port }}
  User: {{ .Values.auth.username }}
  Auth: SCRAM-SHA-256

{{- if include "quench-common.tls.enabled" . }}
The gateway enforces TLS with the chart certificate. Verify it with the CA in Secret
{{ include "quench-common.tls.secretName" . }} (key ca.crt): pass tls=true&tlsCAFile=<ca.crt>.
{{- else }}
The gateway enforces TLS with an auto-generated self-signed cert, so clients MUST
pass tls=true&tlsAllowInvalidCertificates=true (tls.enabled gives it a verifiable one).
{{- end }}

{{- if .Values.auth.enabled }}

Get the password:

  kubectl get secret --namespace {{ .Release.Namespace }} {{ include "documentdb.secretName" . }} \
    -o jsonpath="{.data.{{ include "documentdb.secretPasswordKey" . }}}" | base64 -d

Connect with mongosh:

  mongosh "mongodb://{{ .Values.auth.username }}:<password>@{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}/?tls=true&tlsAllowInvalidCertificates=true&authMechanism=SCRAM-SHA-256"
{{- else }}

WARNING: auth is disabled.
{{- end }}

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
