Kanidm serves HTTPS on {{ include "quench-common.fullname" . }}:{{ .Values.service.port }} for {{ include "kanidm.origin" . }}.
{{- if .Values.ldap.enabled }} LDAPS (read-only) is on port {{ .Values.service.ldapsPort }}.{{ end }}

Set the passwords of the two built-in admins (each run prints a new one):

  kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "quench-common.fullname" . }} -- kanidmd recover-account admin
  kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "quench-common.fullname" . }} -- kanidmd recover-account idm_admin

admin manages the server; idm_admin manages people and groups. Then sign in at {{ include "kanidm.origin" . }}/ui.
