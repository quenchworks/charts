# Quenchworks forgejo

Hardened [Forgejo](https://forgejo.org/) self-hosted Git forge (a community
[Gitea](https://about.gitea.com/) fork) on a minimal, nonroot, 0-CVE image pinned
by digest. Single node; persists its repositories, SQLite DB and generated config
to a PVC. Boots **install-locked** — the web installer is never served.

## Install

```bash
helm install my-forgejo oci://ghcr.io/quenchworks/charts/forgejo
```

Then port-forward and open the web UI:

```bash
kubectl port-forward svc/my-forgejo-forgejo 3000:80
# http://127.0.0.1:3000
```

## Headless boot

The hardened image runs `forgejo web` directly and has no `environment-to-ini`
step, so `FORGEJO__*` env vars are **not** honored. Instead an init container
generates an `app.ini` on the PVC on first boot, containing:

- `INSTALL_LOCK = true` (skips the web installer)
- `SECRET_KEY`, `INTERNAL_TOKEN`, `oauth2.JWT_SECRET` — generated by the forgejo
  binary itself (real, valid values) and persisted on the PVC, so they never
  touch the read-only root filesystem and never rotate on restart
- SQLite DB at `<mountPath>/forgejo.db`, repos under `<mountPath>/git/repositories`

The file is written only if absent, so restarts and upgrades keep your data and
secrets. To customize non-secret settings, edit `config.*` in values.

## Create the first admin

Registration is open by default. To create an admin non-interactively:

```bash
kubectl exec -it my-forgejo-forgejo-0 -- \
  forgejo --config /data/app.ini admin user create \
  --admin --username admin --password 'change-me' --email admin@example.com
```

## Verify the image

```bash
cosign verify ghcr.io/quenchworks/images/forgejo \
  --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

## Values

| Key | Default | Notes |
|-----|---------|-------|
| `image.repository` | `ghcr.io/quenchworks/images/forgejo` | |
| `image.digest` | (CI-written) | Required. Charts pin by digest, never a tag. |
| `replicaCount` | `1` | Stateful single node (SQLite); do not scale out. |
| `containerPort` | `3000` | HTTP port Forgejo binds (nonroot). Wired to `server.HTTP_PORT`. |
| `config.appName` | `Forgejo` | Instance name. |
| `config.rootUrl` | `""` | External base URL (set behind an Ingress). Defaults to `http://localhost:<containerPort>/`. |
| `config.logLevel` | `info` | Console log level. |
| `config.ssh.enabled` | `false` | Built-in git-over-SSH server; exposes a `ssh` service port when on. |
| `config.ssh.port` | `22` | |
| `service.port` | `80` | Service port, forwards to the container's `http` port. |
| `persistence.enabled` | `true` | PVC mounted at `mountPath` (repos + DB + config). |
| `persistence.mountPath` | `/data` | Forgejo work/data dir. |
| `persistence.size` | `8Gi` | |
| `persistence.existingClaim` | `""` | Bind an existing PVC instead of provisioning one. |
| `serviceAccount.create` | `true` | Token automount is off. |
| `rbac.create` | `false` | Minimal empty Role/RoleBinding when enabled. |
| `networkPolicy.enabled` | `true` | Client ingress from the namespace; set `allowExternal: true` to open it. |
| `podDisruptionBudget.enabled` | `true` | `minAvailable: 1`. |

## Security

Runs nonroot (uid 1001) on a read-only root filesystem with all capabilities
dropped. Only the `/data` PVC and an emptyDir `/tmp` are writable. Forgejo serves
`/api/healthz` (returns `{"status":"pass",...}`), used for the startup, liveness
and readiness probes.

## Notes

Single node only: Forgejo stores everything in a local SQLite database plus a
repository tree on the PVC, so it cannot be horizontally scaled. For HA you would
move to an external database and shared storage, tracked as a follow-up.
