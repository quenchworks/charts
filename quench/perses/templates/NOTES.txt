Quenchworks Perses is installed as {{ include "quench-common.fullname" . }}.

The server runs nonroot and serves the dashboard UI and API on container port 8080;
the Service exposes it on port {{ .Values.service.port }}:

  {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Open the UI and check health over a port-forward:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  # UI:     http://127.0.0.1:{{ .Values.service.port }}/
  # Health: http://127.0.0.1:{{ .Values.service.port }}/api/v1/health

{{ if .Values.persistence.enabled }}
Dashboards and projects are stored on a PersistentVolumeClaim at {{ .Values.persistence.path }},
so they survive pod restarts.
{{- else }}
Running with the default file datastore on an ephemeral emptyDir at {{ .Values.persistence.path }}.
Dashboards and projects are LOST on pod restart. Set persistence.enabled=true to
keep them on a PersistentVolumeClaim.
{{- end }}

The image is pinned by digest and signed. Verify it:

  cosign verify ghcr.io/quenchworks/images/perses \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
