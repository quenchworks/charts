Quenchworks Excalidraw is installed as {{ include "quench-common.fullname" . }}.
{{- if include "quench-common.tls.enabled" . }}

TLS is on: Excalidraw serves HTTPS itself (native TLS) on Service port {{ .Values.service.httpsPort }},
which replaces the plain-HTTP port in the URLs below:

  https://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local{{ if ne (int .Values.service.httpsPort) 443 }}:{{ .Values.service.httpsPort }}{{ end }}/

The certificate is in Secret {{ include "quench-common.tls.secretName" . }}; trust its ca.crt (self-signed by default):

  kubectl get secret --namespace {{ .Release.Namespace }} {{ include "quench-common.tls.secretName" . }} -o jsonpath='{.data.ca\.crt}' | base64 -d > ca.crt
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 8443:{{ .Values.service.httpsPort }}
  curl --cacert ca.crt https://localhost:8443/
{{- end }}

The SPA is served by nginx (nonroot) on container port 8080; the Service exposes
it on port {{ .Values.service.port }}:

  {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Open it in a browser over a port-forward:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} 8080:{{ .Values.service.port }}
  # then visit http://127.0.0.1:8080

This is the static, self-hosted Excalidraw app: no backend, no account, and the
read-only root filesystem keeps a writable tmpfs only at /tmp for nginx. Expose it
outside the cluster with your own Ingress or a LoadBalancer Service.

The image is pinned by digest and signed. Verify it:

  cosign verify ghcr.io/quenchworks/images/excalidraw \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
