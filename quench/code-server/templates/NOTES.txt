Quenchworks code-server (VS Code in the browser) is installed as {{ include "quench-common.fullname" . }}.
{{- if include "quench-common.tls.enabled" . }}

TLS is on: code-server serves HTTPS itself (native TLS) on Service port {{ .Values.service.httpsPort }},
which replaces the plain-HTTP port in the URLs below:

  https://{{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local{{ if ne (int .Values.service.httpsPort) 443 }}:{{ .Values.service.httpsPort }}{{ end }}/healthz

The certificate is in Secret {{ include "quench-common.tls.secretName" . }}; trust its ca.crt (self-signed by default):

  kubectl get secret --namespace {{ .Release.Namespace }} {{ include "quench-common.tls.secretName" . }} -o jsonpath='{.data.ca\.crt}' | base64 -d > ca.crt
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 8443:{{ .Values.service.httpsPort }}
  curl --cacert ca.crt https://localhost:8443/healthz
{{- end }}

It runs nonroot and serves the editor on container port 8080; the Service exposes
it on port {{ .Values.service.port }}:

  {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

Open the editor over a port-forward:

  kubectl port-forward svc/{{ include "quench-common.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  # then browse http://127.0.0.1:{{ .Values.service.port }}

{{ if .Values.auth.existingSecret -}}
The login password comes from the Secret "{{ .Values.auth.existingSecret }}" (key {{ .Values.auth.existingSecretKey | default "password" }}).
{{- else if .Values.auth.password -}}
The login password is the value you set in auth.password.
{{- else -}}
A random login password was generated. Read it with:

  kubectl get secret {{ include "quench-common.fullname" . }} -o jsonpath='{.data.password}' | base64 -d; echo
{{- end }}

{{ if .Values.persistence.enabled -}}
Your workspace and editor state persist on the PVC "{{ include "code-server.pvcName" . }}" mounted at {{ .Values.persistence.mountPath }}.
{{- else -}}
persistence.enabled is false — the workspace lives in an emptyDir and is LOST on pod restart.
{{- end }}

The image is pinned by digest and signed. Verify it:

  cosign verify ghcr.io/quenchworks/images/code-server \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
