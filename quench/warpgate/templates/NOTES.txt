Warpgate (bastion) serves its web UI on HTTPS:

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "quench-common.fullname" . }} 8888:{{ .Values.service.httpsPort }}
  open https://localhost:8888/@warpgate   (self-signed until you set your own certificate)

Sign in as "admin" with the generated password:

  kubectl get secret -n {{ .Release.Namespace }} {{ include "warpgate.secretName" . }} -o jsonpath='{.data.admin-password}' | base64 -d; echo

SSH targets go through port {{ .Values.ssh.port }}: ssh <user>:<target>@<this host> -p {{ .Values.ssh.port }}
{{- end }}
