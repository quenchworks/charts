Quenchworks ScyllaDB Open Source is installed as {{ include "quench-common.fullname" . }}.

ScyllaDB Open Source is licensed AGPL-3.0-only and is Cassandra-compatible (CQL).

Connect over CQL from inside the cluster (port {{ .Values.service.cqlPort }}):

  CQL service: {{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.cqlPort }}

The runtime image has no in-image cqlsh, so connect with a throwaway upstream client:

  kubectl run cqlclient --rm -it --restart=Never --image=scylladb/scylla:6.2 -- \
    cqlsh {{ include "quench-common.fullname" . }} {{ .Values.service.cqlPort }}

Then exercise it:

  CREATE KEYSPACE IF NOT EXISTS demo WITH replication =
    {'class':'SimpleStrategy','replication_factor':1};
  CREATE TABLE IF NOT EXISTS demo.t(id int PRIMARY KEY, v text);
  INSERT INTO demo.t(id, v) VALUES (1, 'quench');
  SELECT v FROM demo.t WHERE id = 1;
{{- if .Values.auth.enabled }}

Authentication is ENABLED. ScyllaDB bootstrapped the default superuser
`cassandra` / `cassandra` — log in, then immediately rotate it:

  kubectl run cqlclient --rm -it --restart=Never --image=scylladb/scylla:6.2 -- \
    cqlsh {{ include "quench-common.fullname" . }} {{ .Values.service.cqlPort }} -u cassandra -p cassandra

  ALTER ROLE cassandra WITH PASSWORD = '<new-strong-password>';
{{- else }}

Authentication is OFF (open). Enable it with:

  --set auth.enabled=true

then rotate the bootstrapped cassandra/cassandra superuser (see the chart README).
{{- end }}

Check the node's release version via the unauthenticated REST API (port {{ .Values.service.apiPort }}):

  kubectl exec {{ include "quench-common.fullname" . }}-0 -- \
    sh -c 'wget -qO- http://127.0.0.1:{{ .Values.service.apiPort }}/storage_service/scylla_release_version'

The image is pinned by digest and signed. Verify it:

  cosign verify {{ .Values.image.repository }} \
    --certificate-identity-regexp 'https://github.com/quenchworks/.+' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
