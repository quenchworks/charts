PgDog is listening on {{ include "quench-common.fullname" . }}:{{ .Values.port }} (PostgreSQL protocol).

Connect with any PostgreSQL client, using a user and database from `users`:

  psql "host={{ include "quench-common.fullname" . }}.{{ .Release.Namespace }}.svc port={{ .Values.port }} user=<user> dbname=<database>"

Admin database (SHOW POOLS, SHOW CLIENTS, RELOAD):

  kubectl get secret -n {{ .Release.Namespace }} {{ include "quench-common.fullname" . }} -o jsonpath='{.data.admin-password}' | base64 -d
  psql "host=... port={{ .Values.port }} user=admin dbname=admin"
