The admin page is /admin, user {{ .Values.admin.username }}:

  kubectl get secret -n {{ .Release.Namespace }} {{ include "microbin.secretName" . }} -o jsonpath='{.data.password}' | base64 -d

Anyone who reaches MicroBin can upload. To require a password for uploads, set MICROBIN_UPLOADER_PASSWORD
(extraEnvVarsSecret); to hide the public list, set MICROBIN_PRIVATE: "true" in settings.
